# Review — 22 August 2026

Two read-only reviews of the support-admission pipeline and the engine shape,
run before the human review pass. Findings ranked. Nothing here was fixed.
Test suite at review time: 220 passed.

## A. Support pipeline — fail-open paths

1. **Admission never binds run gold to the frozen probe.** `support_admission.py:161-175`,
   `support_gate_cli.py:21-26`. `RecordedProbeRun.probe_sha256` is a self-declared string;
   gold rows are `{case_id, expected_status, kind}` and cannot recompute the probe hash.
   Fabricated easy runs with the plan's hash pasted in → PASS. Load-bearing hole.
2. **Review context never re-derived from corpus after prepare.** `support_review.py:66-98,
   485-493`. Demonstrated: injected text into `context_text`, rehashed, apply + build exit 0.
   Runner then recomputes context from real source (`support_runner.py:167`) → detector sees
   text the reviewer never saw, no divergence check.
3. **Agent can be its own human reviewer.** `support_review.py:100-120`, `support_cases.py:69-72`.
   Reviewer id is only checked non-blank; no `human:` prefix, no author≠reviewer. Demonstrated:
   `adjudicated` provenance created by `agent:gpt-x`. Contradicts SUPPORT.md:137, ANNOTATION.md:125,
   GATES.md:42.
4. **Agent screen trusts self-reported overlap/absence.** `support_agent_screen.py:147-154`,
   `support_review_html.py:186`. Not recomputed from text; reviewer "apply all" rubber-stamps.
   Caught at build, but the screen's included-group count is the quoted number.
5. **Optional stopping undetectable.** `support_review.py:465-478`, `build_support_probe.py:54-65`,
   `freeze_support_plan.py:28`. No rejection count recorded, no attempt counter, `frozen_at` is
   free text. Flip rows to ambiguous, rebuild, refreeze — every artifact self-consistent.
6. **`excluded_pool_sha256` hashes Groundnut's own holdout list**, not the intersection with
   the imported edition (`support_seeds.py:523`). `--expected-excluded-sources` is the real guard.
7. Self-hashed ≠ signed. All chain artifacts are regenerable by their holder.

Plan schema `groundnut-support-probe-plan/v2` — NOT enforced anywhere: `sampling_seed`,
`source_pool_sha256`, `excluded_pool_sha256`; `group_count` checked in runner only, not at
admission; overlap band enforced via review manifest, never via plan; `frozen_at` never parsed.
Not in schema: per-kind regression rule (hardcoded strict `<` over all kinds,
`support_admission.py:269`), review-manifest sha, detector identity.

Round trip HTML→TSV→apply→build: works, tested with browser-exact CRLF/quoting. One
fragility: stale `localStorage` from an older reviewer build → "columns differ" with no hint.

Test gaps: none of 1–5 covered; reserve replacement untested (`reserve_count=0` in all fixtures);
no browser-format TSV test; html header order / `_DECISION_COLUMNS` coupling unasserted.

## B. Engine shape

1. **Decision/abstention stage is not in the engine.** Only `shadow_composition.py`, not
   exported, reached via `scripts/compose_shadow_receipt.py` scraping CLI JSON by string keys.
   RxClarity run: 105 claims → 63 withheld, 32 needs_validation, 0 supported, 0 questions.
   Structural: question-conditioned components must abstain, and no artifact profile emits
   `verification_question`.
2. **`canonical_cli.py:103` rejects any detector but `ExactSupportDetector` by class.**
   Canonical path can never emit `contradicted`. Undocumented.
3. Wiring: acquire→segment→mechanical→one signal→authority→arena emission→manifest is real
   (`runner.py:105-146`). Islands: navigation (scripts only), signal bundles (produced, consumed
   by nothing), decision, arena adjudication (CLI only), report (does not exist).
4. Five unreconciled outcome vocabularies (`support.py:22`, `shadow_composition.py:17`,
   `coverage.py:94`, `arena.py:252`, README).
5. Doc claims not backed: "standalone engine" (`groundnut/engine.py:9` imports `pipeline`);
   navigation as canonical stage; "can combine signals"; render parity "stops evidence
   disappearing" (manual CLI only); "each CLI documented beside its contract" (4 CLIs, 19 scripts).
6. Bulk without checking value: ten `support_*` modules ~2.5k lines; `support_bakeoff` duplicates
   gate CLI; two relevance abstractions; `parity.py`/`engine.py`/`coverage.py`/
   `segmentation_experiment.py` ~960 lines with no canonical callers; 8 hashed policy objects,
   3 reach a manifest. 11.9k lines in `groundnut/`, canonical path ~3.4k.
7. Remaining unearned: "strong control system" (never adversarially exercised; fail-closed that
   never opens is untested); fail-closed/replay as invariants have no property tests.

## What bears on the admission plan

Before session B, not after: fix A1 (gate loads the probe and checks gold ⊆ probe), A3
(`human:` prefix + author≠reviewer), A5 (build records rejected/ambiguous counts and attempt
number into the probe manifest; plan binds `review_manifest_sha256`). A2 is worth fixing but
the reviewer HTML already embeds the prepared context, so the exposure is tampering, not
accident. B2 must be fixed for the candidate to run at all.
